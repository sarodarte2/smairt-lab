# SMAIRT Adversarial Review

The third anti-bias mechanism, alongside AGENTS.md's stakes rule and
explanation rule: it exists to stop one interpretation from becoming
canonical simply because it was said first and never challenged.

Researcher-invoked only — never run this unprompted.

## Steps

1. Read the current interpretation you're arguing against: the relevant
   stage/question READMEs' `## What it means` and `verdict:` fields.
2. Build the counter-case using only evidence already recorded in this
   project's units — do not introduce outside claims or general
   skepticism:
   - dead ends (`status: dead-end` + their recorded reason)
   - surprises or anomalies visible in the raw logs
   - open questions listed in `STATUS.md`
   - alternatives named but not tried, in any unit's README
3. Output pointed questions that put pressure on the current
   interpretation — not reassurance, not a balanced summary, not a
   softened version to spare the researcher's feelings.
4. If the recorded evidence is genuinely thin, say that plainly rather
   than manufacturing objections; the goal is honest pressure-testing,
   not conflict for its own sake.
